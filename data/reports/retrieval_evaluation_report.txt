RETRIEVAL EVALUATION REPORT
Analytics Vidhya Pinnacle Plus Capstone
============================================================

1. PURPOSE
------------------------------------------------------------
This report compares the retrieval configurations implemented for
the RAG capstone using 10 evaluation questions.

Metric:
  Hit@3 = an expected source document appears in the top 3 retrieved
  results for the question.

Important limitation:
  This is a source-level retrieval metric. It does not by itself
  measure passage relevance, answer quality, groundedness, citation
  correctness, or whether the best passage was ranked first.

2. EVALUATION SET
------------------------------------------------------------
Total questions: 10

Questions cover all 8 source papers, including:
  - plate tectonics and marine biodiversity
  - Pangaea and vicariance/speciation
  - terrestrial biodiversity during Pangaea fragmentation
  - supercontinent cycle and climate
  - early Cambrian palaeogeography and climate
  - Phanerozoic landscape dynamics and biodiversity
  - tropical forest biodiversity
  - origins of New Zealand terrestrial fauna

4. FIVE-WAY COMPARISON
------------------------------------------------------------
The two embedding models both achieved 90.0% Hit@3 as standalone dense
retrievers on this 10-question set.

BM25 also achieved 90.0%, showing that lexical retrieval alone can
recover the expected source for most questions.

The BGE-small + BM25 RRF hybrid achieved 100.0% Hit@3 (10/10), while
the MiniLM + BM25 RRF hybrid achieved 90.0% (9/10).

Therefore, for this evaluation set, BGE-small + BM25 + RRF is selected
as the final retrieval configuration. This is a dataset-specific
experimental result, not a claim that BGE-small is universally better
than MiniLM.

  and diversification of terrestrial organisms?

  02_global_biogeography_pangaea.pdf

MiniLM dense Q10:
  1. 03_pangaea_terrestrial_biodiversity.pdf | page 1 | chunk 3
  2. 01_plate_tectonic_marine_diversity.pdf | page 3 | chunk 4
  3. 01_plate_tectonic_marine_diversity.pdf | page 4 | chunk 2
  Result: MISS

MiniLM + BM25 + RRF Q10:
  1. 01_plate_tectonic_marine_diversity.pdf | page 4 | chunk 5
  2. 01_plate_tectonic_marine_diversity.pdf | page 4 | chunk 4
  3. 03_pangaea_terrestrial_biodiversity.pdf | page 1 | chunk 3
  Result: MISS

The BGE-small + BM25 + RRF run did retrieve the expected Q10 source
within its top three, so the hybrid strategy improved Q10 for BGE-small
but not for MiniLM.

This is a useful failure case for the capstone because it shows that
source-level retrieval can remain sensitive to the embedding model and
ranking behavior.

9. CAPSTONE INTERPRETATION
------------------------------------------------------------
On this 10-question evaluation set:

  - BGE-small dense: 90.0%
  - MiniLM dense: 90.0%
  - BM25: 90.0%
  - BGE-small + BM25 + RRF: 100.0%
  - MiniLM + BM25 + RRF: 90.0%

The selected final retriever is BGE-small + BM25 + RRF because it achieved
10/10 expected-source retrieval on this test set.

The result should be reported as an observed experimental outcome rather
than a universal model ranking.

The next stage is the complete RAG pipeline. It must evaluate whether
the retrieved passages actually support the generated answer and whether
paper title/page citations are correct.
